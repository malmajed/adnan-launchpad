# Adnan's Launchpad

Career platform for Adnan Alabdullatif (EE, KSU 2026): Compass career profiling, four mission tracks,
pipeline and network tracker, weekly check-ins, and an Advisor view (follow.html) where his advisor
follows progress and sends notes and tasks. Single-file PWA, deployed by GitHub Actions to GitHub Pages.
Backend: build/Code.gs (Apps Script on a Google Sheet "Adnan Launchpad Progress").
